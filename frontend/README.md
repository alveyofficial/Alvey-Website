# Frontend
This is the frontend of alvey.study, soley written in Vite React.js, a modified React.js meant to improve runtimes and speed.
It is in **.tsx** and not in **.jsx**

## Notes
- Kindly write **_neat_** and **_legible_** code
- Push all code changes to the `dev` branch
- Only working production versions are allowed to be pushed into the `main` branch

## How to Setup
- Begin by installing all packages with `npm i`
- To run the frontend, use `npm run dev`
