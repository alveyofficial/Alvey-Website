# General
Welcome to alvey.study's github repo!

To run, ensure you have gone into both the `frontend` and `backend` directories, then you can come back here and do this :
- `npm i` to install the packages for this folder
- `npm run dev` within this directory to start both the frontend and backend
- `npm run frontend` within this directory to start **only** the frontend
- `npm run backend` within this directory to start **only** the backend with autorefresh
