# Backend
This is the backend of alvey.study, written in express.js soley for both the main server and api

## Notes
- Kindly write **_neat_** and **_legible_** code
- Push all code changes to the `dev` branch
- Only working production versions are allowed to be pushed into the `main` branch
**Goodluck!**

## How to Setup 
- Use `npm i` to install all required packages
- Fill in all `.env` values, it is located in the `env` directory, if not create one
- You can run backend with `npm run dev`, this comes with live refresh as changes are made
- You could also run it with `npm start`, this has no live refresh
